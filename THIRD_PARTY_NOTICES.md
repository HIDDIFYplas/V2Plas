# Third-party notices

## Circular country flag artwork

V2 Plas bundles circular country flag artwork from [HatScripts/circle-flags](https://github.com/HatScripts/circle-flags), distributed under the MIT License. The GitHub Actions build downloads the SVG artwork and converts it into local Android drawable PNG resources. Flags are bundled into the APK; the application does not request flag images at runtime.

The upstream project describes itself as a collection of circular SVG country flags and identifies the project license as MIT. See the upstream repository for the complete license text and attribution.
